# Arastirma-Yontem-ve-Teknikleri
İstanbul Maratonu’nu Tamamlayan Erkek Koşucuların Performans Düzeyine Göre Tempo Profillerinin Analizi
Bu çalışmada İstanbul Maratonunu 6 saatten kısa sürede tamamlayan erkek koşucuların koşu tempo profillerinin performans düzeyine göre belirleyen veri setinin python yardımıyla işlenmesi amaçlanmıştır.
