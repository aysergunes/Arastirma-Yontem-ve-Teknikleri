# Arastirma-Yontem-ve-Teknikleri
İstanbul Maratonu’nu Tamamlayan Erkek Koşucuların Performans Düzeyine Göre Tempo Profillerinin Analizi

Bu çalışmada İstanbul Maratonunu 6 saatten kısa sürede tamamlayan erkek koşucuların koşu tempo profillerinin performans düzeyine göre belirleyen veri setinin python yardımıyla işlenmesi  ve veriler ışığında bağıl sonuçlara ulaşılması amaçlanmıştır.

Proje dosyasında yer alan Use Case Diagramında, sistemin kullanıcıyla olan etkileşimini ve sistemin temel işlevlerini gösterir. Activity diagramında ise, projede çalışan algoritmanın adım adım mantıksal akışını ifade edilmektedir. Class Diagramında ise projenin mimarisini oluşturan sınıflar ve nitelikleri belirtilmektedir.
